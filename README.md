# 路線偏離測試器 v7 口袋測試版

重點：

- 支援 GPX / KML 路線匯入。
- 匯入後路線保存於本機，重啟 PWA 會自動恢復。
- 開始定位後自動嘗試啟用 Screen Wake Lock。
- 測試階段不因 GPS 品質差而停止偏離警告。
- 語音改為短句：例如「偏移，往回，佳」「偏移，往右回走，不佳」「嚴重偏移，往左回走，嚴重誤差」。
- 黑畫面按鈕會嘗試開啟 iPhone 捷徑「路線測試螢幕最暗」。
- 黑畫面長按 3 秒離開時，會嘗試開啟 iPhone 捷徑「路線測試螢幕最亮」。

## 需要建立的 iPhone 捷徑

1. `路線測試螢幕最暗`：動作加入「設定亮度」，設為 0% 或 1%。
2. `路線測試螢幕最亮`：動作加入「設定亮度」，設為 100%。

注意：網頁呼叫捷徑會跳到「捷徑」App，可能短暫離開 PWA；這是 iOS 限制。
