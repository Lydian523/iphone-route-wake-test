# iPhone 路線偏離測試器｜PWA 原型

用途：在 iPhone 11 Pro 上測試「恆亮口袋 PWA」是否可行。

## 功能

- 匯入 GPX / KML。
- 使用 `navigator.geolocation.watchPosition()` 持續定位。
- 使用 Screen Wake Lock 嘗試保持螢幕恆亮。
- 計算目前位置到 GPX / KML 路線的最近距離。
- 30 / 50 / 80 公尺三段偏離提醒。
- 嗶聲與語音提醒。
- 黑畫面省電模式。
- 長按 3 秒離開黑畫面，降低口袋誤觸。
- 顯示 GPS 精度、定位次數、距離路線、測試紀錄。

## iPhone 測試流程

1. 部署到 GitHub Pages。
2. 用 iPhone Safari 開啟網址。
3. 加入主畫面。
4. 從主畫面開啟 PWA。
5. 匯入 GPX / KML。
6. 按「開始定位」。
7. 按「啟用 Wake Lock」。
8. 按「測試聲音」，確認口袋或耳機聽得到。
9. 按「黑畫面省電模式」。
10. 螢幕朝內放入口袋，台中街上實測。

## 測試重點

- Wake Lock 是否成功。
- 加入主畫面後 Wake Lock 是否仍成功。
- GPS 精度是否穩定。
- 距離路線數值是否合理。
- 30 / 50 / 80 公尺提醒是否太敏感或太慢。
- 黑畫面是否仍會誤觸。
- 聲音是否聽得到。
- 1 小時耗電量。

## 注意

2 公尺偏離不建議作為正式提醒門檻。市區 GPS 飄移很容易超過 2 公尺，尤其高樓、車站、地下街、商場附近。


## v3 更新

- 支援 `.kml` 路線匯入。
- KML 會優先讀取 `LineString` 的 `<coordinates>`。
- 若 KML 只有景點 `Point`、沒有路線線段，會顯示錯誤。
- `.kmz` 目前尚未支援；請先從 Google 我的地圖匯出 KML，或先解壓縮 KMZ 取出 doc.kml。
