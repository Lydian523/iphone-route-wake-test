# iPhone 日本旅行路線提醒器 v11.1

## 本版重點

- 主畫面改為真正地圖、規劃路線、目前位置與下一站標記。
- GPS、Wake Lock、語音改用頂端小燈號；詳細資料收進抽屜。
- 固定底部操作：暫停、我已抵達、臨時景點、更多。
- 新增景點支援：直接點地圖、完整 Plus Code、Google 地圖搜尋、貼上含座標的 Google Maps 網址、目前位置。
- 桌面瀏覽器會顯示 iPhone 11 Pro 尺寸模擬框與 GPS／時間測試控制台。
- 手機開啟時自動填滿畫面，不顯示桌面控制台。
- 保留 V10 的真實手勢 Wake Lock 策略與 GPS watchPosition。

## 部署

將本資料夾內所有檔案放在 GitHub Pages 儲存庫根目錄。更新既有版本時直接覆蓋同名檔案即可。

首次更新建議開啟：

`index.html?v=11.1`

Service Worker 快取名稱：`route-wake-test-v11-1`

## 限制

- OpenStreetMap 地圖圖磚與 Leaflet 函式庫由網路載入；無網路時不保證底圖可用。
- Plus Code 目前支援完整碼，不支援省略前綴的短碼。
- Google 地圖搜尋會另開 Google Maps；純前端版本不串接需金鑰與計費設定的 Places API。
- Google Maps 短網址不一定能直接解析；含 `@緯度,經度` 或查詢座標的網址較容易成功。
- 尚未完成 iPhone 11 Pro 實機與戶外回歸測試。


## v11.1.1 時間計算機更新

- 開啟時自動帶入目前時間。
- 提供 ±5、±10、±20、±30 分鐘快速調整。
- 提供自訂分鐘增加或減少。
- 從景點預計抵達時間開啟時，可直接套用計算結果。
- 計算紀錄保存在本機，最多保留 30 筆。


## v11.1.2 景點彈窗與時間欄位修正

- 點擊地圖景點時，優先顯示剩餘距離與預計抵達時間。
- 景點彈窗提供「跳過」「移除」「編輯」三項操作；編輯改由獨立編輯面板開啟。
- 從預計抵達時間欄位開啟計算機時，改為純時間調整模式，不顯示距離與步行速度。
- 純時間模式按「記錄並套用」後，會立即寫回原本的時間欄位並保存。
- 一般行程時間計算機仍保留距離、速度、停留與緩衝計算。
- Service Worker 快取名稱：`route-wake-test-v11-1-2`。


## v11.1.3 截止時間與行程餘裕

- 時間計算機改為列車、表演、預約等「必須抵達時間」情境。
- 開啟時計入現在時間，輸入截止時間、提前抵達緩衝與截止景點。
- 估算剩餘步行距離、中途停留、整段所需時間、時間餘裕與需要平均步速。
- 根據結果顯示時間充裕、偏緊、幾乎無餘裕或預估來不及。
- 顯示可刪減的中途景點與約可節省時間，並可直接本次跳過。
- 保留時間欄位的純時間加減與回填模式。
- Service Worker 快取名稱：`route-wake-test-v11-1-3`。


## v11.1.4 截止時間防跨日錯誤
- 過去時間不再自動視為隔天。
- 增加今天／明天明確選擇。
- 截止時間已過或緩衝後已無時間時，停止顯示錯誤餘裕並禁止記錄。


## V11.1.7

- 修正完整 Plus Code 解碼。

- 跳過與移除整合進景點編輯。
- 截止時間工具改名為「趕車／表演時間評估」，補上用途說明。
- GPS 詳細頁新增定位、更新、Wake Lock、語音燈號。
- 預設步行速度欄位補上 4 km/h 的規劃基準說明。

## V11.2
- 新增景點的預計抵達時間欄位加入 -10/-5/+5/+10 快速調整，調整後焦點留在欄位可繼續手動修改。
- 新增景點的插入位置改為直接顯示實際站名（設為下一站／插在第 N 站之前或之後／加到行程最後）。
- 底部「暫停」按鈕改為「行程時間評估」，直接開啟評估頁；「更多」選單移除重複入口。
- 暫停／繼續改為長按主頁「下一站」卡片約 0.9 秒切換，並提供畫面與語音回饋。
- 行程時間評估頁重新整理：標題改為「行程時間評估」，用途說明預設收起（標題旁「？」按鈕展開），第一層只留現在時間、必須抵達時間、必須抵達地點、計算結果、可刪減景點與歷史紀錄。
- 必須抵達時間改為點擊後進入獨立設定頁，快速調整鈕移至該頁，套用後才返回評估頁；目前僅處理「今天」情境，時間已過會顯示已過，不再自動推算明天。

## V11.2.1 修正紀錄

- 行程時間評估中「本次跳過」會寫入獨立 skipped 狀態，主畫面地圖立即改成灰色刪除線景點標記。
- 已抵達與已跳過在地圖及景點清單中分開顯示；重設抵達狀態會一併清除跳過狀態。
- 定位光點改為方向箭頭。移動時優先使用 GPS heading，低速或停止時使用 iPhone 方向感測器。
- 按「開始真實定位與方向」時，iPhone 會要求允許動作與方向取用；未允許時仍可定位，但方向箭頭會顯示為未取得。
- 景點清單新增上移／下移按鈕；調整後同步更新地圖編號、目前／下一站、時間評估與備份資料。
- Service Worker 快取更新為 route-wake-test-v11-2-1。


## v11.2.2 修正
- 暫停定義為行程延誤，暫停時放大顯示餘裕時間。
- 移除 Leaflet 左上角縮放按鈕，保留手勢與滾輪縮放。
- 已跳過景點可從地圖彈窗、景點清單或編輯頁恢復。
- 放大方向箭頭並加入醒目的扇形方向指示。


## v11.2.3 修正

- 移除定位圓形光點與方向扇形，只保留黃色方向箭頭。
- 建立統一餘裕狀態：餘裕超過 5 分鐘為綠色、餘裕 0～5 分鐘為黃色、預估遲到為紅色。
- 暫停期間中央大型餘裕監控會依上述狀態切換綠／黃／紅。
- 地圖右下「預估抵達」區塊同步使用相同綠／黃／紅狀態。
- Service Worker 快取更新為 v11.2.3。
